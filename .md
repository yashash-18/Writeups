```
</style>

	<iframe src="https://0a0000ca04eb43638009030c001c00d5.web-security-academy.net/my-account">
	</iframe>
```
**-> After injecting the HTML make sure that "Click here" option and delete option are aligned properly, if not adjust using "top,left" objects**<br>
**-> once it is done view the exploit and check if the cursor on the "Click here" changes to pointing a hand, then it is being framed properly.. also check the iframe whether the src is correct**<br>
**-> We are hiding the main webpage with the "delete" option underneath the "Click here" option.. so when the user fall for it he has been tricked and the account is deleted without his knowing**<br>
